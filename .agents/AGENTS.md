# 全局与项目代理行为准则 (AGENTS.md)

## 1. 严格的代码提交与版本控制约束 (CRITICAL)

- **严禁擅自 Commit 或 Push 代码**：在用户没有明确发出“提交代码”或“推送仓库”的指令之前，代理**绝对禁止**自动执行任何 `git commit` 或 `git push` 操作。
- **验证优先与版本可回退性**：所有修改必须仅保持在本地工作区，经过完整的自动化测试与用户实物测试验证并明确确认后，方可由用户指令触发提交。

## 2. 行为准则与响应规范

- **行动前解释**：在执行任何工具调用前必须先对用户进行简要解释。
- **不擅自猜测逻辑与路径**：严禁推测不存在的逻辑或未验证的代码。
